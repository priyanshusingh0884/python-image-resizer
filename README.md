# 🖼️ Python Image Resizer

A simple Python application that resizes images using OpenCV. It allows users to resize an image by specifying a scaling percentage.

## ✨ Features

- Reads images using OpenCV.
- Resizes images based on a specified percentage.
- Calculates new width and height automatically.
- Saves the resized image.
- Preserves original image channels.

## 🛠️ Technologies Used

- Python
- OpenCV (cv2)

## 📦 Installation

Install the required library:

```bash
pip install opencv-python
```

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Place your source image in the project directory.
4. Update the source and destination filenames in the Python script.
5. Set your desired resizing percentage.
6. Run:

```bash
python main.py
```

## ⚙️ Configuration

You can modify these parameters:

- `source`: Input image filename.
- `destination`: Output image filename.
- `scale_percent`: Percentage used to resize the image.
